立即用清晰的 Dev、Staging 和 Production 标签标记您的浏览器。
在跨环境工作时避免代价高昂的操作失误。

跨多个环境工作容易引发严重错误——例如在 Staging 环境该执行的操作却误操作在了 Production 上。

WebLabeler 使用可自定义的标签和颜色，直接在浏览器中直观标记您的当前环境。

主要功能：

🎨 自定义环境标签：为 Dev、Staging、Production 或任何自定义环境设计标签——自由调整形状、颜色、位置和透明度。

🔖 Favicon 角标：在浏览器标签栏中一眼区分各个环境。

🌐 基于域名的规则：通过灵活的规则类型（包括正则表达式支持），根据域名自动应用环境标签。

🖱 快速切换：无需离开当前页面即可启用或禁用标签。

📦 导入 / 导出：与团队共享标签配置，或通过 URL 自动同步更新。

📥 轻松迁移：从其他扩展导入现有标签，立即开始使用 WebLabeler。

🔄 跨设备同步：通过 Google Chrome 账户同步，在所有设备上保持环境标签一致。

🌙 深色模式支持：夜间或弱光环境下同样舒适易用。

适用场景：

✅ 避免误操作将更改部署或测试到生产环境
✅ 立刻识别 staging 和 production 版本的区别
✅ 在 Dev、Staging 和 Production 环境中安全测试功能
✅ 管理多个项目而不混淆环境或标签页

在每个环境中都能自信工作。
