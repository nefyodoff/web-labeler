Dev・Staging・Productionのラベルでブラウザをすぐに識別。
環境をまたいだ作業でのミスを防ぎましょう。

複数の環境で作業していると、StagingではなくProductionで操作してしまうような重大なミスが起きやすくなります。

WebLabelerは、カスタマイズ可能なラベルと色を使って、ブラウザ上で現在の環境を視覚的に表示します。

主な機能:

🎨 カスタム環境ラベル: Dev・Staging・Production、またはカスタム環境向けのラベルを作成できます。形状・色・位置・不透明度を自由に調整可能。

🔖 ファビコンバッジ: ブラウザのタブバーで各環境を瞬時に見分けられます。

🌐 ドメインベースのルール: ドメイン名をもとに、柔軟なルールタイプ（正規表現対応）で環境ラベルを自動適用します。

🖱 クイックトグル: ページを離れずにラベルの有効/無効を切り替えられます。

📦 インポート / エクスポート: ラベル設定をチームと共有したり、URLから自動同期したりできます。

📥 簡単な移行: 他の拡張機能からラベルをインポートして、すぐにWebLabelerを使い始められます。

🔄 デバイス間の同期: Googleアカウント同期でラベル設定をすべてのデバイスに同期します。

🌙 ダークモード対応: 深夜作業や暗い環境でも快適に使えます。

主な用途:

✅ 誤ってProductionに変更をデプロイ・テストしてしまうのを防ぐ
✅ StagingとProductionのバージョンを瞬時に見分ける
✅ Dev・Staging・Productionの各環境で安全に機能テストを行う
✅ 複数プロジェクトで環境やタブを混同しないよう管理する

どの環境でも自信を持って作業しましょう。
