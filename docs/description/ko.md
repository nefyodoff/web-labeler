Dev, Staging, Production 레이블로 브라우저를 즉시 표시하세요.
여러 환경에서 작업할 때 발생하는 실수를 피하세요.

여러 환경에서 작업하다 보면 Staging 대신 Production에서 실행하는 것 같은 치명적인 실수가 발생할 수 있습니다.

WebLabeler는 사용자 정의 레이블과 색상을 사용하여 브라우저에서 현재 환경을 시각적으로 표시합니다.

주요 기능:

🎨 커스텀 환경 레이블: Dev, Staging, Production 또는 사용자 정의 환경용 레이블 디자인 — 모양, 색상, 위치, 투명도 조절 가능.

🔖 파비콘 배지: 브라우저 탭 표시줄에서 환경을 즉시 구분할 수 있습니다.

🌐 도메인 기반 규칙: 도메인 이름을 기반으로 정규식 지원을 포함한 유연한 규칙 유형을 사용하여 환경 레이블을 자동으로 적용합니다.

🖱 빠른 전환: 현재 페이지를 벗어나지 않고 레이블을 활성화 또는 비활성화합니다.

📦 가져오기 / 내보내기: 팀과 레이블 설정을 공유하거나 자동 업데이트를 통해 URL에서 동기화합니다.

📥 간편한 마이그레이션: 다른 확장 프로그램에서 기존 레이블을 가져와 즉시 WebLabeler를 사용할 수 있습니다.

🔄 기기 간 동기화: Google Chrome 계정 동기화를 통해 모든 기기에서 환경 레이블을 동기화하세요.

🌙 다크 모드 지원: 야간 작업이나 저조도 환경에서도 편안하게 사용할 수 있습니다.

활용 사례:

✅ 실수로 변경 사항을 Production에 배포하거나 테스트하지 않도록 방지
✅ Staging과 Production 버전을 즉시 구분
✅ Dev, Staging, Production 환경에서 안전하게 기능 테스트
✅ 환경이나 탭을 혼동하지 않고 여러 프로젝트 관리

어떤 환경에서도 자신 있게 작업하세요.
